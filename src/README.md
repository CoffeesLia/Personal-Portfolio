# Portfólio — Cecília Pereira


Este repositório contém um **portfólio pessoal** em React, pensado para apresentar habilidades em desenvolvimento web e design. O estilo é cozy/minimalista com paleta clara.


## Estrutura


- `App.jsx` — componente React principal (single-file para início rápido)
- (quando você migrar para um projeto real, recomendamos organizar em `src/components`, `src/styles`, etc.)


## Como rodar localmente


1. Crie um novo projeto React (Vite recomendado):


```bash
npm create vite@latest meu-portfolio -- --template react
cd meu-portfolio
```


2. Copie o conteúdo do `App.jsx` deste arquivo para `src/App.jsx` do seu projeto criado.
3. Instale e configure Tailwind (opcional, recomendado). Se preferir, rode sem Tailwind e ajuste classes.
4. Inicie o projeto:


```bash
npm install
npm run dev
```


## Deploy rápido


- GitHub Pages: use `gh-pages` ou configure GitHub Actions.
- Vercel / Netlify: conectar o repositório e deploy automático.
