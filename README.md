# Portfólio — Cecília Pereira


Este repositório contém o código-fonte do meu **portfólio pessoal** em React, com foco em design minimalista e aconchegante (cozy).


## 🧩 Estrutura de pastas
```
src/
├── components/
│ ├── Header.tsx
│ ├── Hero.tsx
│ ├── About.tsx
│ ├── Skills.tsx
│ ├── Projects.tsx
│ ├── Experience.tsx
│ └── Contact.tsx
├── App.tsx
├── index.html
├── index.css
└── main.tsx
```


## 🚀 Rodando localmente

Copie os arquivos para dentro da pasta `src/` e rode:
```bash
npm install
npm run start
```


## 🌸 Estilo
- **Tailwind CSS** para estilização.
- Paleta de cores: bege, marrom claro e creme.
- Fonte principal: [Poppins](https://fonts.google.com/specimen/Poppins).
